# Game

`:game` contains the authored Adventurers of Rylween content.

Important areas:

- `src/main/kotlin/rylween/game/RylweenGame.kt` is the main DSL-authored game
  script.
- `RylweenAudio.kt` declares the sound effects, music, and ambient loops, and
  is included from `RylweenGame.kt`.
- `RylweenCompiledGame.kt` is a thin facade over the authored model
  (`nextRylween`, `nextDsl`). `:tools`, the bitmap web runtime's built-in
  bundle, and tests compile from it.
- `RylweenTestScenarios.kt` contains replay fixtures and authored runtime
  states for verification. It stays in `main` because those named state images
  are compiled into the playable bundle and selected by runtime smoke/playtest
  launchers such as `--state fresh-replay` and `--state strong-replay`.
- Typed handles (`Items`, `Monsters`, `States`, `Sounds`, and so on) are
  generated from these sources by `:game:generateGameCatalogHandles` into
  `build/generated/gameCatalog/` before compilation; do not edit them.
- `src/main/resources/tiles` contains ANSI map-window scene art (town
  buildings, caves, encounters, camp, death).
- `src/main/resources/ansi` contains the full-screen ANSI title and frame.
- `src/main/resources/bitmap` contains bitmap assets used by the bitmap web
  runtime.
- `src/main/resources/audio` contains the sound effects, music, and ambience
  generated by `support/audio`.
- `src/main/resources/adventurers-of-rylween.md` is the original manual, shown
  in the game.

For authoring syntax, extension examples, and DSL/runtime ownership rules, see
the [DSL authoring guide](../docs/dsl-authoring.md).

Reusable DSL, compiler, validation, runtime, and renderer code should not be
added here. This module should stay focused on game data, scripts, fixtures, and
assets.
