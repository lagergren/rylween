# DSL Origin Scratch

This directory archives the early full-file DSL sketch and conversation notes
that led into the current Kotlin DSL migration.

These files are intentionally kept out of the main authoring path:

- `rylween-full-scratch.dsl.kts` is the active game-specific scratch source.
- `src/main/kotlin` is the active Kotlin DSL/runtime implementation.
- The files here are historical reference only.
