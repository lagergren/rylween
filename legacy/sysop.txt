Adventurers of Rylween - Part I, the Rise and Fall of Baron Ydarg
is a fantasy roleplaying game for Xenolink BBS.

---

Install it like this for Xenolink BBS:

1. Create a directory called Doors:Rylween/
2. Copy the files Rylween, MAP.DAT and all the #?.ANS files to it.
3. Edit your doormenu: XenolinkDoor "^20000^1^Rylween/Rylween"
   It runs fine without any specific stack allocations on my system,
   but do this just to be on the safe side. If two nodes use Rylween
   at once, nice unpredictable effects will be created.
4. Make it possible for the users to download and read through
   the manual before they start playing.
5. Read the manual.
6. Have fun!

---

As a CLI door, run it like this:

RYLWEEN <cli> <username>

Example:

Rylween CLI "Marcus Lagergren"
Rylween CLI Testuser

The Xenolink door is a bit faster and checks baud rate and ANSI
graphics before running Rylween. Find another way to do this for 
the CLI door.

See above for other information.

---

This is a very complex game, and there is no point in starting playing
it before you have read the manual, at least once. It is also a good
idea to print the manual, so that you can use it as a reference during
the game.

Optdata: Run this every midnight or whenever you feel for it. It will
         optimize the user data for Rylween, remove bad records, 
         remove inactive players (with 0 experience points), these
         have obviously only played the game once, and quickly
